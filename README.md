# PROACTIVE-CARE
ProActiveCare AI is a predictive glucose intelligence web application that analyzes glucose trends, detects instability patterns, and forecasts metabolic risk using AI-driven logic.


🩺 ProActiveCare – AI-Based Diabetes Management System
📌 Project Overview

ProActiveCare is a web-based AI-inspired diabetes management system designed to help patients monitor glucose levels and assist doctors in tracking patient health data.

The application provides real-time glucose tracking, personalized diet recommendations, monthly progress visualization, downloadable medical reports, and a dedicated doctor dashboard for patient monitoring.

This project demonstrates the integration of healthcare analytics, data visualization, and AI-inspired logic into a practical web-based healthcare solution.

🚀 Key Features
👤 Patient Module

Secure login system

Glucose level input and validation (40–400 mg/dL range)

Real-time glucose status display (Low / Normal / Warning / Critical)

Personalized diet recommendations based on glucose level

AI-based health suggestions

Monthly progress visualization using charts

Downloadable medical report (PDF format)

Local storage data persistence

👨‍⚕️ Doctor Panel

Separate doctor login

Access to patient glucose history

Centralized patient monitoring view

Simplified health tracking interface

📊 Data Visualization

Line chart for daily glucose trend

Bar chart for monthly glucose report

Average, highest, and lowest glucose summary

📄 Report Generation

PDF medical report including:

Patient details

Latest glucose level

Health status

AI-generated advice

🧠 AI Logic Used

The system applies rule-based AI-inspired logic to:

Classify glucose levels into categories:

Low Sugar (<70 mg/dL)

Normal (70–140 mg/dL)

Warning (141–199 mg/dL)

Critical (≥200 mg/dL)

Provide condition-based diet plans

Generate automated medical suggestions

Analyze monthly glucose data trends

While this is a prototype system, it simulates how AI can assist in preventive healthcare decision-making.
